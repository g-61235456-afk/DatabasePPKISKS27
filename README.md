# DatabasePPKISKS27 Android APK

The GitHub Actions workflow at `.github/workflows/build-apk.yml` builds the Android debug APK from the project ZIP and uploads it as an artifact.

## Build APK
1. Open the repository's **Actions** tab.
2. Select **Build DatabasePPKISKS27 APK**.
3. Click **Run workflow** if no run is active.
4. Open the completed run and download **DatabasePPKISKS27-APK** under Artifacts.

APK artifact retention: 30 days.
